# ToolNexa AI: search visibility and validation
- 60 utility URLs and 11 distinct Studio URLs have individualized titles, descriptions, related links and practical guides. The Bill Maker Studio is an alternate entry point to the canonical invoice-generator page, not an extra search landing page.
- Keep SITE_PUBLIC_LAUNCH_ENABLED=true only on public production; never open account or checkout pages to indexing.
- In Search Console, select the verified toolnexaai.com property, submit https://toolnexaai.com/sitemap.xml, inspect the homepage and priority tools, test live URL and request indexing when appropriate.
- Start with invoice-generator, gst-calculator, image-to-pdf, merge-pdf, studio/enhance, studio/background-remove, studio/passport-social and studio/image-to-vector. These are proposed search targets, not measured keyword demand.
- Use Performance > Search results to compare pages and queries, clicks, impressions, CTR and average position over comparable periods. Check Page indexing for exclusions and Core Web Vitals for field data when available.
- Improve pages that have actual impressions with accurate examples and useful information. Do not purchase ranking links, fabricate reviews, stuff keywords or use fake last-modified dates. Google chooses titles/snippets and rankings; no guaranteed position or indexing.
